# Hajemti, brief design (réponses de Shaman, 50 questions)

## Marque
- Nom : **ouvert au changement**, direction **française/anglaise internationale** (« hijama » = ventouses, pas la beauté). Logo : attend le nom.
- Utilisateur n°1 : **les propriétaires de salons** (ceux qui paient). Public : femmes d'abord, hommes clairement inclus.
- Sensations : **luxe, chaleureux, fiable**. Vouvoiement.
- Langues : **FR + AR + EN**. Arabe standard dans l'interface, dialecte tunisien dans le marketing. RTL complet.
- Identité tunisienne : **touches subtiles**.

## Visuel
- Thème **clair ET sombre**, au choix de l'utilisateur. Sombre = **aubergine / prune** (plus noir pur).
- Palettes : montrer **3 options** (1 proche de l'actuel, 2 audacieuses).
- Titres : garder le serif élégant. Petit texte : **plus grand sur mobile**.
- Effets (aurora, particules) : **on garde**. Hero : image/dégradé fixe, pas de vidéo.
- Images : **générées par IA**, style **abstrait et artistique, sans visages**. Illustrations **sur mesure**.
- Salon sans photo : **motif de marque + initiales**.
- Perf : équilibre richesse / vitesse.

## Pages et produit
- Accueil : **6 à 8 sections**, **deux chemins** (réserver / lister mon salon). Chiffres inventés → **remplacer par des objectifs** (« rejoignez les 100 premiers salons »).
- Carte + liste (accueil et recherche). Filtres mobile : au choix du designer.
- Page salon : photos, prestations, avis, réservation, **bien répartis**. Mobile : **bouton Réserver collant en bas**.
- Confirmation : **animation + carte type ticket + message WhatsApp**.
- Thèmes de salon : **quelques presets sûrs**. Marque plateforme **bien visible**.
- Confiance : badge **vérifié** + badge **hygiène/certification**.
- Fidélité : **visible et ludique**. Paiement : non décidé (laisser de la place).
- Catégorie vedette : **ongles et beauté**.
- Page partenaires : message **plus de clients + moins d'admin + site à soi**.

## Dashboard
- Propriétaires = utilisateurs de smartphone basiques. **Mobile et bureau à égalité**. Clair/sombre au choix.
- Accueil dashboard : **agenda du jour + chiffres/revenus**.

## Livrables et façon de travailler
- Livrables : **brand kit + templates réseaux sociaux** (Instagram, Facebook, TikTok, WhatsApp).
- Shaman propose, le développeur valide. Délai : **2 à 3 mois**.
- Format : **maquettes HTML interactives**. Code réel **plus tard**, après validation.
